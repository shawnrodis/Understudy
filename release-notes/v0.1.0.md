First release: an AI operator for your own Windows PC.

**Added**
- A windowless Rust engine with an HTTP/JSON control API on port 18769. It binds only to the PC's Tailscale IPv4 address, or to loopback when Tailscale is down — never `0.0.0.0`.
- Bearer-token auth on every endpoint. The token is generated on first run and stored only on the controlled PC at `%APPDATA%\Understudy\auth.token`.
- Per-monitor, DPI-aware screenshots (GDI BitBlt) — the desktop is never treated as one stretched virtual screen.
- Mouse and keyboard injection (`SendInput`) using per-monitor logical coordinates, plus app launch/kill, scoped file transfer, and command execution as the engine's user.
- A local action log (`actions.log`) recording every request, including rejected ones. Tokens and file contents are never logged.
- A Flutter tray app that only monitors and stops the engine: connection status, monitors, action log, Tailscale setup, and the Quit kill switch.
- An NSIS installer: `Understudy_Setup_0.1.0.exe`.
- `CONTROL_API.md`, the complete API contract, written so an AI controller can operate the PC without guessing.

**Fixed before release**
- CI: dropped the deprecated `useMaterial3` flag, and fixed the NSIS staging path (`/NOCD`) with loud checks so an empty staging directory fails the build instead of the installer step.

**Known limitations**
- Screenshots are Windows-only; other hosts return HTTP 501 for capture.
- The installer is unsigned, so SmartScreen prompts on first run.
