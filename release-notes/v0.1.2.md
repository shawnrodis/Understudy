The app now runs the engine itself, checks for updates, and quits reliably.

**Added**
- **Engine auto-start and watchdog.** The tray app spawns the engine from its own install folder on launch and restarts it if it dies. Retries are throttled so an instantly-crashing engine cannot hot-loop spawns, and a "Start engine" button forces one.
- **Update check.** A launch check against the GitHub Releases API, at most once per 24h, silent when there is nothing new or the check fails. The Status tab also has "Check for updates", which always reports its result.
- **Download and install.** When a newer release exists, the Status tab shows its version and release notes with a Download and install button. Nothing is ever installed silently: the app downloads the installer, quits (engine included), then launches it elevated — one UAC prompt, expected. Declining it just means relaunch and try again.
- An optional desktop shortcut in the installer.

**Fixed**
- **Quit is a reliable kill switch.** Quit stops the engine and exits even when the API cannot be reached, and never leaves the engine running behind a closed app.
- The engine writes `connection.json` atomically, with the port it actually bound, so the app and the API can never disagree about the port.

**Changed**
- The engine is fully windowless: no console window and no taskbar button of its own.
- `--port` and `--data-dir` flags for running the engine outside the app.

**Installer**
- `Understudy_Setup_0.1.2.exe`
