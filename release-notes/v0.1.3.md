Adds a controller connection card to the Status tab.

**Added**
- A **Controller connection** card showing the address a controller needs: Tailscale device name, Tailscale IP, and the control port, with a copy button. It says plainly when Tailscale is not connected instead of showing a stale address.
- The engine reports the machine's Tailscale device name in `GET /tailscale/status` (`device_name`), taken from `tailscale status --json` — host name first, falling back to the first DNS label. It is `null` rather than a guess when it cannot be determined.
- `CONTROL_API.md` documents the new field.

**Not shipped**
- **There is no installer for this version.** This tag does not build: `app/lib/main.dart` uses `Clipboard` without importing `package:flutter/services.dart`, so `flutter analyze` and the Windows build both fail. Use **v0.1.4**, which contains this card and fixes the build.
