Fixes the Tailscale install path and adds token rotation.

**Fixed**
- **Tailscale install actually works now.** Version resolution reads the first versioned entry of the stable package listing — there is no `VERSION` file on that track, so the old lookup 404'd and a blank version field failed. If resolution still fails, the error says so and asks for an explicit version.
- The installer now runs hidden and elevated (one UAC prompt, no console window), and success is only reported after the install is verified: `tailscale.exe` present and answering `tailscale version`.
- Install and login results are shown on the Tailscale tab where the buttons are, instead of a notice on the Status tab — a failed install used to look like nothing happening.

**Added**
- **Single-instance guard** on loopback port 18771: launching Understudy again raises the existing window and exits, so there are never two windows, two engines, or two taskbar icons.
- **Pairing-token rotation** via `POST /auth/rotate`. The old token is invalid immediately, and the new one is never returned over the API — the app re-reads `auth.token` from disk. Use it the moment a token may have leaked.
- `CONTROL_API.md` expanded to cover the install, login, and rotation endpoints.

**Installer**
- `Understudy_Setup_0.1.1.exe`
